# NT ALPHA Site — V1

Primeira versão oficial do site público NT ALPHA.

## Características
- Next.js + TypeScript
- CSS próprio e modular
- Sem Tailwind
- Sem Bootstrap
- Visual discreto e institucional
- Responsivo
- Preparado para Supabase e Vercel

## Estrutura visual
Os estilos estão separados na pasta `styles/`.

## Execução
```bash
npm install
npm run dev
```
